# 学习笔记目录

按《Solidity-60天学习计划.md》执行，每天一篇：

```text
notes/
├─ day01.md       # 当天：学到的概念（用自己的话）
├─ week1-review.md
└─ ...
```

每篇笔记建议包含：

1. **今天学了什么**（3–5 条，禁止抄定义，必须复述）
2. **亲手跑的代码/实验**（合约名 + 结果）
3. **报错与解决**（报错原文 → 原因 → 修复）
4. **明天先解决的一个疑问**

对应练习合约放 `contracts/`，周项目与毕业项目放 `projects/`。

每天结束前提交：

```powershell
git add -A
git commit -m "Day NN: 主题一句话"
```
